# Smart Fix Pro — ملفات التحديث

هذا المستودع يحتوى **ملفات التثبيت والتحديث فقط** — لا يوجد به أى كود للبرنامج.

برنامج Smart Fix Pro يفحص هذا المكان تلقائياً من داخله:

> الإعدادات ← تحديثات البرنامج ← «فحص التحديثات الآن»

فإذا وجد نسخة أحدث، ينزّلها ويتحقق من بصمتها (sha256) ثم يركّبها ويعيد
تشغيل نفسه. بيانات المحل لا تُلمس فى أى خطوة، وإذا تعثّر التركيب يرجع
البرنامج للنسخة السابقة من تلقاء نفسه.

### كل إصدار هنا يحتوى

| الملف | الغرض |
|---|---|
| `SmartFixPro-vX-update.zip` | ملف التحديث |
| `SmartFixPro-vX-update.zip.sha256` | بصمة التحقق |
| `latest.json` | بيانات الإصدار التى يقرأها البرنامج |

### سياسة الإصدارات

يُحتفظ بالإصدار الحالى ونسخة واحدة سابقة فقط؛ الأقدم من ذلك يُحذف.

للاستفسار أو الدعم الفنى تواصل مع مطوّر البرنامج.
